# Groundwork Gems

This repository contains the Groundwork Ruby gems for form workflows, case management, policy rules, and government data attributes.

## Gems

- [`case_management`](./case_management)  
  Groundwork case management Rails engine: intake forms, workflow routing, and examiner task queues.  
  Docs: [`case_management/README.md`](./case_management/README.md)

- [`forms_core`](./forms_core)  
  Groundwork multi-page form flow core with no Rails dependency.  
  Gem source: [`forms_core`](./forms_core)

- [`forms_rails`](./forms_rails)  
  Groundwork multi-page form Rails adapter (controllers and routing helpers).  
  Gem source: [`forms_rails`](./forms_rails)

- [`government_attributes`](./government_attributes)  
  Structured, validated US government data types for ActiveModel/ActiveRecord models.  
  Docs: [`government_attributes/README.md`](./government_attributes/README.md)

- [`rules_engine`](./rules_engine)  
  Groundwork rules engine for lazy-evaluated, explainable policy rules in pure Ruby.  
  Gem source: [`rules_engine`](./rules_engine)
